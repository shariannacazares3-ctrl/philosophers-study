# The Scholar's Chamber

A candlelit daily rite for the philosopher in the making: light the candle, break the seal, hear a voice from the lineage, take one scholarly act, and enter evidence in the ledger.

Everything lives in `index.html` (inline CSS and JS). Open it in a browser, or publish it with GitHub Pages (Settings → Pages → Deploy from branch → `/ (root)`).

Ledger entries are stored only in your browser's `localStorage`, on the device you write them on.
